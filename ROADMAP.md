# Roadmap

## v0.1.0 - Current

- IndexedDB local-first client.
- Outbox and cursor-based pull sync.
- User registration and login.
- Persistent SQLite event log.
- Docker development setup.

## v0.2.0 - Reliability

- WebSocket transport with polling fallback.
- Exponential backoff and dead-letter events.
- Configurable conflict strategies.
- PostgreSQL adapter and migrations.
- Expiring sessions and rate limiting.

## v0.3.0 - Developer Experience

- Publish `@syncbridge/client` to npm.
- React and Vue examples.
- TypeScript declarations.
- Hosted demo and performance dashboard.
- Multi-tenant organization support.
